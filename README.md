# 🌾 Farmer Theory

An interactive, source-grounded analysis of an **Old World** question: in a settler-pumping capital, when does pausing to build a **Farmer specialist** on a grain farm beat just spamming settlers?

Every number is traced to the game's own files (`…/Old World/Reference/{XML,Source}`) — the single build queue, settler/farmer costs, grain→growth via granary adjacency, family bonuses (Landowners), leader archetypes, and rating scaling.

**Live:** https://alcaras.github.io/ow-farmer-theory/

## What it does
- Breaks down exactly where capital growth comes from.
- Models the **single build queue** (Settler vs Farmer are mutually exclusive).
- Lets you pick **starting family, leader archetype, and leader strength** and watch the settler timeline + break-even update.

Open `index.html` locally via `file://` or use the live link. No build step, no dependencies.
